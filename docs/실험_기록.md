## 메모
- v1 test 점수는 공개 데이터셋 안에서 나눈 점수. 같은 사진의 증강본이 train·test에 섞였을 수 있어 실제보다 높게 나올 수 있음 → 부산 사진 60장 라벨로 따로 확인할 것.
- 저장 위치: 공유 드라이브 `편한길로/runs/v1/` (`weights/best.pt`, `results.csv`)
- (11/18 확인) v1은 계단 데이터셋 11,285장 중 2,959장만 쓰였음. 드라이브에서 바로 읽을 때 파일 일부가 안 보인 것으로 추정 → v2부터 사진은 Colab 디스크(`/content/raw`)에 받아서 씀.
